## 📝 Todo App

A simple and clean Todo application built with **React**. This app allows you to manage your daily tasks efficiently — add, complete, and delete todos with ease. Data is persisted in **localStorage**, so your todos are saved even after refreshing the page.

### ✨ Features
- ✅ Add new todos
- ✔️ Mark todos as complete/incomplete
- 🗑️ Delete todos
- 💾 Persistent storage with localStorage
- 💬 Motivational quote on the header

### 🚀 Demo
The app is live and deployed on Vercel. Try it out here: [Todo App](https://todo-app-react-beta-two.vercel.app/)
